### W07 `rmcp.model.request_state_wire.version_of_spec`

```lean
@[step]
theorem version_of_spec (s : Slice U8) :
    version_of s ⦃ (result : Option Version) =>
      match result with
      | some .V1 => (components s.val).head? = some versionV1
      | some .V2 => (components s.val).head? = some versionV2
      | none =>
        (components s.val).head? ≠ some versionV1 ∧
        (components s.val).head? ≠ some versionV2 ⦄
```

### W08 `rmcp.model.request_state_wire.parse_rs1_spec`

Statement (as signed off):

```lean
@[step]
theorem parse_rs1_spec (s : Slice U8)
    (h_count : s.val.count dot < Usize.max) :
    parse_rs1 s ⦃ (result : Option Rs1Parts) =>
      match result with
      | some p => components s.val = [versionV1, p.body.val, p.tag.val]
      | none => ∀ body tag, components s.val ≠ [versionV1, body, tag] ⦄
```

- Proof file: `formal/proofs/Proofs/Model/RequestStateWire/ParseRs1.lean`
- `#print axioms`: `'rmcp.model.request_state_wire.parse_rs1_spec' depends on axioms: [propext, Classical.choice, Quot.sound]`
- Build time: 2.2–2.4 s (module build), 2.5 s (elab of the file)
- Proof difficulty: Medium. Count `≠ 3`: the result `none` follows from the first conjunct of `component_count_spec` (W06), `c = (components s).length`, since a three-element list has length 3. Count `= 3`: the first `next_dot` cannot return `s.len()` (else one component), so `d1 < s.len()` and `d1 + 1` does not overflow; likewise the second (else two components), which also gives `d1 + 1 ≤ d2` for the `Range` index. The tail then has exactly one component, so it is `s.drop (d2 + 1)` (`components_eq_singleton_of_length_eq_one`). The three index step lemmas give `slice 0 d1`, `slice (d1+1) d2`, `drop (d2+1)`.

### Text identity checker (record copy)

This is the S06 checker with `NAMES` extended to the five S10 statements. The copy that is run
at incorporation is embedded in `docs/review/W-batch-incorporation.md`, step 0 (same text).

```python
# Text identity of the S06 and S10 statements: signed-off draft vs staged recall vs proof files.
# Usage: python3 -I textid.py <repo>   (exit 0 iff all names identical)
import re, sys, glob, pathlib
R = pathlib.Path(sys.argv[1]) / "formal"
NAMES = ["b64_len_spec","key_length_ok_spec","check_kid_len_spec","bytes_eq_spec","next_dot_spec",
         "component_count_spec","version_of_spec","parse_rs1_spec","parse_rs2_spec",
         "transcript_v1_spec","transcript_v2_spec","decode_expiry_spec","is_expired_spec",
         "open_frame_spec","frame_spec","frame_roundtrip"]
PFX = "rmcp.model.request_state_wire."
def strip_comments(t):
    t = re.sub(r"/-.*?-/", " ", t, flags=re.S)          # block and doc comments
    return re.sub(r"--[^\n]*", " ", t)
def stmt(text, kw, name):
    t = strip_comments(text)
    end = r":=" if kw == "theorem" else r"(?=#guard_msgs|\brecall\b|\Z)"
    m = re.search(r"\b%s\s+(?:%s)?%s\b(.*?)%s" % (kw, re.escape(PFX), re.escape(name), end), t, re.S)
    return None if not m else " ".join(m.group(1).replace(PFX, "").split())
draft  = (R/"specs/Drafts/RequestStateWire.lean").read_text()
staged = (R/"specs/Drafts/Staged/RequestStateWire.lean").read_text()
proofs = "\n".join(p.read_text() for p in sorted((R/"proofs/Proofs/Model/RequestStateWire").glob("*.lean")))
ok = 0
for n in NAMES:
    d, s, p = stmt(draft, "theorem", n), stmt(staged, "recall", n), stmt(proofs, "theorem", n)
    same = d is not None and d == s == p
    ok += same
    print(("same " if same else "DIFF ") + n + ("" if same else f"\n  draft={d}\n  staged={s}\n  proof={p}"))
print(f"{ok}/{len(NAMES)} identical"); sys.exit(0 if ok == len(NAMES) else 1)
```
