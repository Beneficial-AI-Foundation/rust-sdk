`serde_json.error.Error` is the placeholder opaque type `axiom serde_json.error.Error : Type` in
`formal/trusted/Rmcp/TypesExternal.lean` (Aeneas-generated template, not yet reviewed). It comes
from the Charon configuration: `serde_json` is opaque (only signatures translated), so the type
`serde_json::Error` is translated as an axiom. E01 and E03 reach it only through their result
type: `RequestStateError` has two constructors carrying a `serde_json::Error` (the JSON wrappers'
error, which these functions never produce). The proofs do
not use any property of it; the dependency is a type, not a behavioural assumption. It cannot be
removed by a proof change: any statement about a function returning `RequestStateError` depends on
it.

With the current audit scope (`scripts/lean-guard.sh axioms`: every trusted axiom used by a
`Defs`/`Proofs`/`Specs` constant must be in `formal/trusted/axioms.lock`), incorporating E01 or E03
makes the `axioms` check fail until the line
`serde_json.error.Error sha256:144d771dea1262a6e2ed2f4d749a0ea7467bcb76f86dafe4c902036992abc701`
is added to `formal/trusted/axioms.lock`. **E01 and E03 are therefore not complete until S08/S09
settles this placeholder**: the S08/S09 conversion in progress replaces it with a non-axiom

@[step]
theorem open_authenticated_body_spec (body : alloc.vec.Vec Std.U8) (now_ms : Std.I64) :
    open_authenticated_body body now_ms ⦃ (result :
        core.result.Result (alloc.vec.Vec Std.U8) RequestStateError) =>
      match result with
      | .Ok payload =>
        expiryLen ≤ body.val.length ∧

### Text identity checker (embedded; run at step 0, before moving any file)

Adapted from the checker at the end of `evidence/S06.md` (names, prefix and paths changed).

```python
# Text identity of the S07 statements: signed-off draft vs staged recall vs proof files.
# Usage: python3 -I textid.py <repo>   (exit 0 iff all names identical)
import re, sys, pathlib
R = pathlib.Path(sys.argv[1]) / "formal"
NAMES = ["open_authenticated_body_spec", "validate_key_length_spec", "b64_len_spec"]
PFX = "rmcp.model.request_state.RequestStateCodec."
def strip_comments(t):
    t = re.sub(r"/-.*?-/", " ", t, flags=re.S)          # block and doc comments
    return re.sub(r"--[^\n]*", " ", t)
def stmt(text, kw, name):
    t = strip_comments(text)
    end = r":=" if kw == "theorem" else r"(?=#guard_msgs|\brecall\b|\Z)"
    m = re.search(r"\b%s\s+(?:%s)?%s\b(.*?)%s" % (kw, re.escape(PFX), re.escape(name), end), t, re.S)
    return None if not m else " ".join(m.group(1).replace(PFX, "").split())
draft  = (R/"specs/Drafts/RequestState.lean").read_text()
staged = (R/"specs/Drafts/Staged/RequestState.lean").read_text()
proofs = "\n".join(p.read_text() for p in sorted((R/"proofs/Proofs/Model/RequestState").glob("*.lean")))
ok = 0
for n in NAMES:
    d, s, p = stmt(draft, "theorem", n), stmt(staged, "recall", n), stmt(proofs, "theorem", n)
    same = d is not None and d == s == p
    ok += same
    print(("same " if same else "DIFF ") + n + ("" if same else f"\n  draft={d}\n  staged={s}\n  proof={p}"))
print(f"{ok}/{len(NAMES)} identical"); sys.exit(0 if ok == len(NAMES) else 1)
```
